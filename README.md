# camodevops

Source for [camo.devops.online](https://camo.devops.online) — a static site generated by `generate_site.py` into `output/`, served either from Cloudflare Workers (`wrangler.jsonc`, `npm run deploy`) or the Docker stack (`docker-compose.yml`, `deploy.sh`).

## Studio OS

[`studio-os/`](studio-os/) holds the **Studio OS** blueprint — the Next.js 16 + TypeScript + Prisma/PostgreSQL take on the same studio journey (contacts with the Hat system, pipeline with Won → auto-project, graph view, studio clock, gear cage, Eve assistant). Currently the project scaffolding — README, `package.json` + lockfile, `prisma.config.ts` — with app source and `prisma/schema.prisma` to land as it's built out. See [`studio-os/README.md`](studio-os/README.md).

## CamoFlow OS

[`camoflow-os/`](camoflow-os/) holds **CamoFlow OS** — the one-stack business command app (Inquiry → Deal → Booked Project → Deliver → Paid) built as a single-file React artifact, including the Kyra agent harness with its MCP-shaped tool registry and human-approval Policy Gate. See [`camoflow-os/README.md`](camoflow-os/README.md) for the module map, the harness design, and the porting/extend path onto this repo's Cloudflare Workers stack.
